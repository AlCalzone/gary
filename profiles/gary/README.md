# Gary's own profile

This profile lets Gary triage its own repository, `AlCalzone/gary`. It does nothing unless an instance on your machine names it.

It is also a small real example of a profile. Start your own from `profiles/template/`.

- Every issue is checked for instructions aimed at agents, sorted into bug or feature, and checked for value.
- A request that belongs in one project's profile is declined with a pointer to the profile.
- The maintainer gets three cards: Accept, Refine and Decline.
- Nothing is implemented without an Accept. The instance sets `maxAutoFixesPerRun` to `0`.
